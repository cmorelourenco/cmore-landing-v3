Four ways to write to people from C-MORE.

Each direction is built from the landing page v3 system: Figtree, graphite and coral, the beige neutrals, the pixel chevron and the drawn 2px card. Every direction is shown as a sign-in code, a password reset and a welcome email.

Built for inboxes

Tables, inline styles and a 600px column. Figtree loads where the client allows it and falls back to Arial, the documented substitute. Images are PNG and JPG, never SVG.

Ready to fill

The template files use merge tags such as {{first_name}}, {{code}} and {{reset_url}}. The Pixel sign-in code uses {{code_1}} to {{code_6}}.

Before sending

Host the images folder on a CDN and swap the relative paths for absolute URLs. The Sphere header uses a background image, so Outlook for Windows shows the plain beige fallback.
